# TapSpark

TapSpark is a tiny SwiftUI iOS toy app. Tap the screen or the center sparkle button to create animated bursts, build a combo, and chase a best score.

## Run

1. Open `TapSpark.xcodeproj` in Xcode.
2. Select an iPhone simulator or a connected device.
3. Press Run.

The project uses SwiftUI, has no third-party dependencies, and targets iOS 17.0 or newer.
